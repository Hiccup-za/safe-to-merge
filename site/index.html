    What we ask Jev

    Jev is TypeSafe AI's System One model. It doesn't write. It answers typed questions with calibrated probabilities.

    Read the Jev docs
    • verdictchoice Safe, needs review, or block?
    • riskscore How risky is this change, trivial to high?
    • tests_adequatenoul Are the changes covered by tests in this PR?
    • breaking_changenoul Will this break behaviour, an API or a schema?
    • sensitive_areanoul Does it touch auth, payments or secrets?
    • blockingnoul Per open thread: must this be resolved first?
    • causechoice Per failing check: the PR, flaky, infra, or unrelated?
